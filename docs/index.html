// features

왜 noop인가요?

⚡

설치 없이 실행

Python 표준 라이브러리만 사용합니다. pip install이 필요 없고, 어떤 환경에서도 즉시 실행됩니다.

🤖

Claude Code 자동 연동

Stop hook으로 Claude Code가 작업을 마칠 때마다 자동 실행됩니다. 별도 명령어를 입력할 필요 없습니다.

🌍

6개 언어 지원

한국어, English, 日本語, العربية, Русский, Français. 언어 선택 메뉴에서 원하는 언어를 고르세요.

📦

확장 가능한 콘텐츠 팩

JSON 파일만 추가하면 새로운 퀴즈 팩을 만들 수 있습니다. 커뮤니티가 함께 만드는 콘텐츠 생태계.

🎮

다양한 게임 타입

선다형 퀴즈, 빈칸채우기, Snake 게임까지. 유휴 시간에 맞는 가볍고 다양한 게임들을 즐기세요.

💡

이름의 의미

"no operation"의 약어. 아무것도 안 하는 척하지만, 실제론 배우고 있다는 아이러니에서 탄생했습니다.

// installation

설치 방법

1단계. 저장소를 클론하세요.

git clone https://github.com/saysun34/noop.git
cd noop

2단계. 직접 실행하거나 Claude Code 스킬로 등록하세요.

# 직접 실행
python3 launch.py

# Snake 게임으로 실행
NOOP_GAME=snake python3 -m noop

3단계. Claude Code에서 스킬로 사용하세요.

# Claude에게 이렇게 말하세요
"noop 실행해줘"
"잠깐 게임 하나 켜줘"
런타임Python 3.8+
의존성없음 (표준 라이브러리만)
플랫폼macOS / Linux
트리거Claude Code Stop hook
