## TUI 라이브러리: Python curses

```python
import curses

def main(stdscr):
    curses.start_color()
    curses.curs_set(0)       # 커서 숨기기
    stdscr.nodelay(True)     # 논블로킹 입력
    # 게임 루프
    while True:
        stdscr.clear()
        # 렌더
        stdscr.refresh()

curses.wrapper(main)
```

## Claude Code Hooks 트리거

```json
// .claude/settings.json
{
  "hooks": {
    "Stop": [
      { "type": "command", "command": "python skill/launcher.py" }
    ]
  }
}
```

- `Stop` hook: 에이전트가 작업 완료 후 대기 진입 시 → 게임 시작
- `PreToolUse`: 특정 명령(Bash) 실행 전 → idle 감지
