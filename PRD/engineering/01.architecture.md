# 01. 전체 아키텍처

## 컴포넌트 다이어그램

```
[Claude Code Agent]
       │
       │ Stop hook / PreToolUse hook
       ▼
[launcher.py]  ← 스킬 진입점
       │
       ├── [ad_fetch.py]  →  광고 서버 API (Cloudflare Worker)
       │         └── 로컬 캐시 (ads_cache.json)
       │
       ├── [game_engine.py]
       │         ├── intro.py     ← 인트로/아웃트로 화면
       │         ├── quiz.py      ← 퀴즈 게임 (fill/block/choice)
       │         ├── snake.py     ← 스네이크 게임
       │         └── typing.py   ← 타이핑 레이서
       │
       └── [renderer.py]  ← curses 기반 렌더러
                 ├── 더블 버퍼링 (curses 기본)
                 ├── 창 크기 관리 (52col × 17row 기준)
                 └── collapsed / expanded 상태 관리
```

---

## 게임 루프

```
초기화
  ↓
render_intro()          ← 로고 + 로딩 + 키 대기
  ↓
render_ad()             ← 광고 3초 (스킵 가능)
  ↓
while True:
  handle_input(key)
    ├── Ctrl+\ → toggle collapsed
    ├── Ctrl+Q → break
    └── 게임별 키 처리
  update_state()
  render()              ← stdscr.clear() + addstr() + refresh()
  sleep(16ms)           ← ~60fps
  ↓
render_outro(stats)     ← 세션 통계 + 카운트다운
```
