# 01. 퀴즈 타입 상세 정의

## fill — 빈칸채우기

```json
{
  "type": "quiz",
  "subtype": "fill",
  "items": [
    {
      "id": "fill-001",
      "template": "파이썬에서 리스트 마지막 요소는 list[___] 로 접근한다",
      "blanks": [
        { "index": 0, "answer": "-1", "hint": "음수 인덱스" }
      ],
      "explanation": "음수 인덱스는 뒤에서부터 접근해요."
    },
    {
      "id": "fill-002",
      "template": "___ 함수는 이터러블의 각 요소에 함수를 적용한다. 예: ___(str, [1,2,3])",
      "blanks": [
        { "index": 0, "answer": "map" },
        { "index": 1, "answer": "map" }
      ],
      "explanation": "map()은 lazy evaluation으로 동작해요."
    }
  ]
}
```

**규칙**
- `___` 등장 순서 = `blanks[].index` 와 매핑
- 빈칸 여러 개면 Tab으로 다음 칸 이동
- `hint`는 선택 필드

---

## block — 블럭이동하기

```json
{
  "type": "quiz",
  "subtype": "block",
  "items": [
    {
      "id": "block-001",
      "question": "다음 코드를 올바른 순서로 배열하세요",
      "blocks": [
        { "id": "b1", "text": "return result" },
        { "id": "b2", "text": "result = []" },
        { "id": "b3", "text": "for i in range(n):" },
        { "id": "b4", "text": "    result.append(i * 2)" }
      ],
      "answer": ["b2", "b3", "b4", "b1"],
      "shuffle": true,
      "explanation": "초기화 → 루프 → 연산 → 반환 순이에요."
    }
  ]
}
```

**규칙**
- `answer`: 정답 블럭 id 순서 배열
- `shuffle: true`면 로드 시 blocks 순서를 랜덤으로 섞음
- 인터랙션: `←→` 커서이동, `Space` 선택/해제, 선택 후 `←→` 으로 위치 이동, `Enter` 제출

## choice — 선다형

```json
{
  "type": "quiz",
  "subtype": "choice",
  "items": [
    {
      "id": "ch-001",
      "question": "파이썬 GIL에 대해 맞는 설명은? (1개 선택)",
      "options": [
        { "id": "o1", "text": "멀티스레드 CPU 연산을 막는다" },
        { "id": "o2", "text": "멀티프로세스도 제한한다" },
        { "id": "o3", "text": "I/O 작업도 블로킹한다" },
        { "id": "o4", "text": "PyPy에서도 동일하게 동작한다" }
      ],
      "answer": ["o1"],
      "multi": false,
      "explanation": "GIL은 스레드 간 CPU 연산만 제한해요. I/O는 해제돼요."
    },
    {
      "id": "ch-002",
      "question": "불변(immutable) 타입을 모두 고르세요",
      "options": [
        { "id": "o1", "text": "tuple" },
        { "id": "o2", "text": "list" },
        { "id": "o3", "text": "str" },
        { "id": "o4", "text": "dict" }
      ],
      "answer": ["o1", "o3"],
      "multi": true,
      "explanation": "tuple, str, int, float 등이 불변 타입이에요."
    }
  ]
}
```

**규칙**
- `multi: false`: Space 선택 시 다른 선지 자동 해제 (단일 선택)
- `multi: true`: Space로 복수 선택 가능
- 인터랙션: `←→` 선지이동, `Space` 선택/해제, `Enter` 제출
