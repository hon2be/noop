# 00. 콘텐츠 팩 스키마

## 디렉토리 구조

```
my-python-quiz/
  ├── pack.json        ← 메타데이터 + 설정
  └── content.json     ← 실제 문제/콘텐츠
```

---

## pack.json

```json
{
  "id": "python-quiz-beginner",
  "version": "1.0.0",
  "title": "Python 기초 퀴즈",
  "description": "파이썬 입문자를 위한 문법 퀴즈 100선",
  "author": {
    "name": "saysun34",
    "url": "https://github.com/saysun34"
  },
  "tags": ["python", "beginner", "quiz"],
  "lang": "ko",
  "license": "CC-BY-4.0",
  "games": ["quiz", "flashcard"],
  "difficulty": "beginner",
  "category": "dev"
}
```

### category 허용값
- `dev` — 개발상식 (Python, Git, CS 등)
- `korean` — 한국어 (맞춤법, 속담, 문학 등)
- `english` — 영어 (어휘, 문법, 표현 등)
- `news` — 시사상식 (뉴스, 사회, 역사 등)
- `nonsense` — 넌센스 (수수께끼, 말장난 등)

### games 필드 허용값
- `quiz` — 퀴즈 게임 (fill / block / choice)
- `flashcard` — 플래시카드
- `typing-racer` — 타이핑 레이서

### difficulty 허용값
- `beginner` / `intermediate` / `advanced`

---

## content.json 공통 래퍼

```json
{
  "type": "quiz",
  "subtype": "fill",
  "items": [ ... ]
}
```

### type 허용값
- `quiz` — 퀴즈 계열 (subtype 필수)
- `typing` — 타이핑 레이서

### subtype 허용값 (type: quiz일 때)
- `fill` — 빈칸채우기
- `block` — 블럭이동하기
- `choice` — 선다형

---

## 검증 규칙

```python
REQUIRED_PACK_FIELDS = ["id", "version", "title", "author", "games", "lang"]
SUPPORTED_TYPES      = ["qa", "typing", "choices", "sequence"]
SUPPORTED_GAMES      = ["quiz", "flashcard", "typing-racer"]

# id: lowercase + hyphen only (정규식: ^[a-z0-9-]+$)
# version: semver (x.y.z)
# items: 최소 1개 이상
```
