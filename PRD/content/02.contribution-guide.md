# 02. 콘텐츠 기여 가이드

## 기여 흐름

```
1. pack.json + content.json 작성
2. 로컬 검증 (validator 실행)
3. GitHub PR 또는 레지스트리 API 업로드
4. 자동 스키마 검증 (CI)
5. 승인 후 마켓플레이스 등록
6. 에이전트에서 팩 이름으로 설치
```

```bash
# 설치 예시
> /install-pack python-quiz-beginner
```

## 광고 시스템

### 소스 우선순위

```
1순위: 자체 광고 서버 (Cloudflare Worker)  ← NOOP_AD_SERVER_URL
2순위: EthicalAds API                      ← ETHICALADS_TOKEN + ETHICALADS_PUBLISHER
3순위: 로컬 캐시 (1시간 TTL)
폴백:  광고 없이 게임 진행
```

초기부터 두 소스 모두 운영. 환경변수로 활성화.

### 자체 광고 서버 응답 포맷 (Cloudflare Worker)

```json
{
  "headline": "Deploy in seconds",
  "content":  "Vercel makes frontend deployment effortless.",
  "cta":      "Try free →",
  "link":     "https://vercel.com",
  "view_url": ""
}
```

### EthicalAds API

- POST `https://server.ethicalads.io/api/v1/decision/`
- `copy.headline` / `copy.content` / `copy.cta` 텍스트 필드 직접 사용
- CPM $2~3, 최소 정산 $50, 매달 15일 지급
- 신청: [ethicalads.io/publishers](https://www.ethicalads.io/publishers/)

### 노출 정책
- 게임 완료 후 + 10문제마다 (총 문제 수 5개 이상일 때) 노출
- 3초 카운트다운, ← / → 로 [스킵] / [방문] 선택 후 Space/Enter 확정
- q 키로 즉시 스킵
- 텍스트 배너 + 아스키아트 지원
- 개발자 관련 서비스만 허용 (SaaS, 클라우드, 개발 도구 등)
- 노출 추적: `view_url` 자동 호출
- 클릭: 마우스 미지원, **Enter 키로 브라우저 열기** (Mac: `open`, Linux: `xdg-open`)
- 클릭 추적: `track_click()` 호출 (추후 URL 기반 추적 확장)

### 아스키아트 (ascii_art) 규격

`ads.json` 또는 광고 서버 응답에 `ascii_art` 배열을 추가하면 텍스트 위에 그래픽 영역이 표시됩니다.

```json
{
  "ascii_art": [
    "  ╔═══════════════╗  ",
    "  ║  >_ hello.py  ║  ",
    "  ║  ...          ║  ",
    "  ╚═══════════════╝  "
  ]
}
```

**규격 (반드시 지킬 것)**

| 항목 | 값 | 설명 |
|------|-----|------|
| 최대 줄 수 | **7줄** | 초과 줄은 렌더러가 무시 |
| 최대 가로 | **42 시각 컬럼** | 반각 문자 1칸, 전각·한글 2칸 |
| 미달 줄 수 | 자동 패딩 | 빈 줄로 채워 항상 7줄 확보 |
| 정렬 | 자동 가운데 정렬 | 렌더러가 아트 영역 안에서 중앙 배치 |

**너비 계산 예시**

```
"  ╔══════════════════════╗  "
 ↑                          ↑
 공백 2                   공백 2
 ╔+═×22+╗ = 24 반각문자 = 24 컬럼  →  총 28 컬럼  ✓ (42 이하)
```

**한글/이모지 포함 시**

```
"  안녕 Hello  "
   ↑↑         각 한글 = 2컬럼
   2×2=4 + 5 + 2 = 11컬럼  ← 이런 식으로 직접 세어볼 것
```

이모지(🚂 등)는 터미널마다 너비가 다를 수 있어 권장하지 않음.
가급적 ASCII 박스 문자(`─│┌┐└┘╔╗╚╝`) + 반각 특수문자(`░▒▓▲△`)로 제작.
