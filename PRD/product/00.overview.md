# 00. 프로덕트 개요

## 제품명
**noop** — no operation. while you wait.

## 한 줄 정의
터미널 에이전트의 유휴 시간에 미니게임과 학습 콘텐츠를 띄우는 Claude Code 스킬

## 핵심 가설
개발자는 빌드/테스트 대기 중 아무것도 안 한다.
→ 이 시간을 가볍고 유익하게 채우면 자연스럽게 수용된다.
→ 개발자 타겟 광고는 CPM이 높아 수익 모델로 유효하다.

## 목표
1. 개발자 유휴 시간에 자연스럽게 진입
2. 학습 콘텐츠(퀴즈, 타이핑 등) 제공
3. 광고 수익 창출
4. 커뮤니티 콘텐츠 생태계 구축

## 배포 형태
Claude Code 스킬 (Skill) + Plugin으로 패키징해 마켓플레이스 배포

## 성공 지표
- DAU (스킬 실행 횟수)
- 세션 평균 길이
- 콘텐츠 팩 기여자 수
- 광고 클릭률 (CTR)
