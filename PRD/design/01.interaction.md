# 01. 키보드 인터랙션 정의

## 전역 단축키 (항상 동작)

| 키 | 동작 |
|---|---|
| `h` | 창 접기 / 펼치기 토글 |
| `q` | 스킬 종료 |

> **Mac 주의**: `Ctrl+\`는 SIGQUIT 시그널로 프로세스를 강제 종료시키고, `Ctrl+Q`는 터미널 flow control 키라 curses에 전달되지 않음. 단순 문자키(`h`, `q`)를 전역키로 사용하고, launcher.py에서 `signal.SIG_IGN`으로 시그널 무시 처리.

---

## 게임별 키 정의

### fill — 빈칸채우기

| 키 | 동작 |
|---|---|
| 문자 입력 | 빈칸에 타이핑 |
| `Tab` | 다음 빈칸으로 이동 |
| `Shift+Tab` | 이전 빈칸으로 이동 |
| `Backspace` | 한 글자 지우기 |
| `Enter` | 제출 |

### block — 블럭이동하기

| 키 | 동작 |
|---|---|
| `←` `→` | 블럭 커서 이동 |
| `Space` | 블럭 선택 / 해제 |
| `←` `→` (선택 중) | 선택된 블럭 순서 이동 |
| `Enter` | 제출 |

### choice — 선다형

| 키 | 동작 |
|---|---|
| `←` `→` | 선지 이동 |
| `Space` | 선택 / 해제 |
| `Enter` | 제출 |
| (multi: false) Space | 선택 시 다른 선지 자동 해제 |

---

## 통합 키맵 요약표

```
키          fill     block        choice     전역
────────────────────────────────────────────────
←→          -        커서/이동    선지이동   -
Space       -        선택/해제    선택/해제  -
Tab         빈칸이동  -            -          -
Enter       제출      제출         제출       -
Backspace   지우기    -            -          -
h           -        -            -          접기/펼치기
q           -        -            -          종료
```

## 창 크기 정의

- 목표 크기: 가로 9cm × 세로 6cm
- 터미널 기준 (14pt 모노스페이스): 약 52 col × 17 row
- 구현 방식: 상대값으로 처리 (터미널 크기 감지 후 비율 맞춤)

```python
cols, rows = shutil.get_terminal_size()
GAME_W = min(52, cols - 4)
GAME_H = min(17, rows - 6)
```
