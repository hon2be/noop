# 00. 화면 흐름

## 전체 생명주기

```
스킬 ON (Hook 트리거)
  ↓
[인트로 화면]
  - 로고 등장 (줄별 순차 렌더)
  - 로딩바 애니메이션 (콘텐츠 팩 로딩)
  - "아무 키나 눌러 시작하기"
  ↓
[광고 화면] (3초, 아무 키로 스킵)
  ↓
[게임 화면]
  - 퀴즈 / 타이핑 / 스네이크 등
  - Ctrl+\ 로 접기/펼치기 가능
  ↓
[아웃트로 화면]
  - 정상 종료: 세션 통계 + 3초 카운트다운
  - 강제 종료: "빌드가 끝났어요!" 메시지
  ↓
스킬 OFF
```

## 인트로 화면 3단계

### 1단계 — 로고 등장 (0.5초)
```
┌──────────────────────────────────────────────┐
│                                              │
│   ███╗   ██╗ ██████╗  ██████╗ ██████╗       │
│   ████╗  ██║██╔═══██╗██╔═══██╗██╔══██╗      │
│   ██╔██╗ ██║██║   ██║██║   ██║██████╔╝      │
│   ██║╚██╗██║██║   ██║██║   ██║██╔═══╝       │
│   ██║ ╚████║╚██████╔╝╚██████╔╝██║           │
│   ╚═╝  ╚═══╝ ╚═════╝  ╚═════╝ ╚═╝           │
│                                              │
│              while you wait.                │
│                                              │
└──────────────────────────────────────────────┘
```

### 2단계 — 로딩바 채워짐 (1초)
- 10% → "콘텐츠 팩 로딩 중..."
- 50% → "문제 섞는 중..."
- 80% → "광고 가져오는 중..."
- 100% → "준비 완료!"

### 3단계 — 시작 대기
- "아무 키나 눌러 시작하기" (blink)
