# 00. 스킬 패키징

## 스킬 구조

```
dev-skill/
  ├── SKILL.md               ← 에이전트 지시문 (언제/어떻게 사용하는지)
  ├── scripts/
  │   ├── launcher.py
  │   ├── renderer.py
  │   ├── game_engine.py
  │   ├── games/
  │   │   ├── quiz.py
  │   │   ├── snake.py
  │   │   └── typing_racer.py
  │   ├── ad_fetch.py
  │   └── validator.py
  └── packs/
      └── (기본 번들 콘텐츠 팩)
```

---

## SKILL.md 설계

```markdown
# dev-idle-game skill

## 언제 사용하나
- 빌드/테스트 명령 실행 후 대기할 때
- 에이전트가 Stop 상태에 진입할 때
- 사용자가 "게임 해" / "심심해" 같은 발화를 할 때

## 실행 방법
`python {skill_dir}/scripts/launcher.py --game quiz --ad true`

## 광고 정책
- 광고는 게임 시작 전 3초 표시
- 사용자가 아무 키 누르면 스킵 가능
```

## Claude Code Hooks 연동

```json
// .claude/settings.json
{
  "hooks": {
    "Stop": [
      {
        "type": "command",
        "command": "python ~/.claude/skills/dev-idle-game/scripts/launcher.py"
      }
    ]
  }
}
```
